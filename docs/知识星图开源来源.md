# 知识星图的开源组件与原创边界

- react-force-graph-3d：用于3D力导向图与节点交互。上游https://github.com/vasturiano/react-force-graph，MIT许可。
- Three.js：用于三维球体、光晕与Canvas文字精灵。上游https://github.com/mrdoob/three.js，MIT许可。
- React/React DOM：界面状态与组件渲染。上游https://github.com/facebook/react，MIT许可。
- Lucide：界面图标。上游https://github.com/lucide-icons/lucide，许可按实际安装包保留。
- pywebview：原生Windows WebView2窗口。上游https://github.com/r0x0r/pywebview，许可按安装包原文保留。

Blinko仅为深色卡片/侧栏的视觉参考，没有复制其GPL源码、品牌图像、吉祥物或整套应用。知页的界面布局、SQLite数据映射、保护流程和业务适配代码在本仓库实际提交。不得把上述组件的完整实现称作本组从零实现。

tools/collect_galaxy_licenses.py从实际安装的包收集原始许可与NOTICE，发行包保留在“第三方许可”。该目录同时可能包含开发工具许可，不代表每个工具都进入运行程序。正式采用第三方源码或素材时需按其实际许可处理。
