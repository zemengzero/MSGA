# C 日期筛选边界修复与回归说明

负责人：万语，U202414607，GitHub `ZYQY218`。日期：2026-11-02。

## 修复内容

在最新 main 上复查日期筛选接入层，发现结束日期为 `9999-12-31` 时，直接对北京时间日期加一天会超出 Python 可表示年份，返回 `OverflowError: date value out of range`。

修复位置：`src/zhiyeteam/galaxy_api.py`。普通日期继续按北京时间取次日零点；只有本地日期加一天溢出时，先转为 UTC，再加一天。最后一天的排他上界仍可表示为 `9999-12-31T16:00:00+00:00`，无需拒绝该日期。

区间语义仍为起点包含、终点排除。新回归验证最晚一天的起点、起点前一微秒、当天最后一微秒和下一日零点。也验证仅传结束日期 `0001-01-01` 的有效 UTC 边界，防止简单地把所有日期都先转 UTC 而引入最早日期回归。

同步保留了 main 已有的笔记内查找延迟快照修正，没有重复修改该实现。
