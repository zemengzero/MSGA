验证与交付
Python：python -m unittest discover -s tests -v。
前端：frontend 目录 npm ci、npm run build、npm test。
打包：Windows 上 python tools/build_galaxy.py。
实体：python tools/frozen_galaxy.py，使用隔离数据目录，检查原生窗口、画布、保存、C 搜索及正常退出。
具体本次运行结果、时间、源码提交和 EXE SHA256 以正式发布包“验证”目录与文件清单为准。
这些检查来自本机自动执行；跨电脑兼容、现场真人使用与尚未接入的 B 功能仍需各自实际验证。

运行
正式版软件/Start-Demo.cmd：独立演示库，打开即呈现真实笔记与关联组成的星图。
软件/Start-Personal.cmd 或双击 ZhiYeGalaxy.exe：正式个人库，空库不自动填充演示笔记。
需要 Windows x64 和 Edge WebView2 Runtime；发行程序无需 Python/Node，运行时不下载前端资源。
正式版 v1.1.0 应设为 GitHub Latest；v1.0.0 与 v1.1.0-a1 作为历史版本保留。
