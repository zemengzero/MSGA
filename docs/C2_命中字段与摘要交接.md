## API 与兼容策略

`src/zhiyeteam/search.py` 新增 `search_hits`，参数与 `search_notes` 完全一致：

```python
search_hits(store, keywords="", tags=(), deleted=False, *,
            updated_from=None, updated_before=None)
```

返回 `list[SearchHit]`。它直接调用 `search_notes`，再为每个返回的笔记生成展示数据，不复制筛选与排序算法。原 `search_notes` 仍返回 `list[Note]`，旧界面使用 `note.id`、`note.title` 的调用保持兼容。日期、关键词、多标签 AND、标题优先排序和回收站语义均沿用 C1。

`src/zhiyeteam/search_presenter.py` 提供不可变的 `SearchHit` 和纯展示函数。关键词的空白分词及 ASCII 大小写处理由两种 API 共用。

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `note` | `Note` | 完整笔记；ID、标题、正文、标签、时间等仍从该对象读取 |
| `matched_fields` | `frozenset[str]` | `title` / `body` 中实际出现任一关键词的字段集合；空关键词为空集合，标签和日期条件不制造关键词命中 |
| `snippet` | `str` | 纯文本正文摘要，最多 120 个 Unicode 码点，计入省略号；空正文或仅空白正文返回空串 |

字段集合无顺序；界面请按“标题、正文”的固定顺序显示，勿依赖集合遍历顺序。一个词在标题、另一个在正文时，完整搜索仍按两字段合并后的内容判断 AND。

## 摘要规则与限制

1. 折叠换行、制表符和连续空白为单个空格，并去掉首尾空白。
2. 折叠后不超过 120 字符时保留全文；长正文有命中时，以正文中最早出现的关键词为中心，最多保留其前 30 字符，向后截取。
3. 无正文命中（如只命中标题或空关键词）时，取正文开头。
4. 前后有省略时分别使用 `…`，并计入总长；按 Python 字符截取，中文和 emoji 不按 UTF-8 字节截断。
5. 匹配只折叠 ASCII A–Z，与旧搜索一致；不会扩展为所有 Unicode 字母的大小写匹配。

摘要不承诺呈现所有查询词，特别是词分散在长文或单个查询词超过摘要预算时。是否满足 AND 由完整正文搜索决定，不能再次仅用摘要过滤结果。120 个码点不保证等于 120 个视觉字形，组合字符或 emoji 序列可能被分开。

这里返回普通字符串，不解析 Markdown 或执行 HTML。正文中的 `<script>`、`<b>` 等字面内容可保留在摘要中；D 应使用文本控件展示，若采用 HTML 展示必须先做文本转义，不能把摘要直接作为 HTML 注入。

## 给 D 的调用片段与文案

```python
from zhiyeteam.search import search_hits

# updated_from / updated_before 的构造见 C1_更新时间过滤交接.md。
hits = search_hits(store, keywords="动态规划", tags=["课程"],
                   updated_from=updated_from, updated_before=updated_before)
for hit in hits:
    note_id = hit.note.id
    title = hit.note.title
    fields_text = "、".join(
        label for field, label in (("title", "标题"), ("body", "正文"))
        if field in hit.matched_fields
    ) or "未指定关键词"
    snippet_text = hit.snippet or "（正文为空）"
    # 将 title、fields_text、snippet_text 放入文本控件；按 note_id 打开原笔记。
```

建议列表或详情文案：“命中位置：标题、正文”“摘要”。空关键词显示“命中位置：未指定关键词”；空摘要可显示“（正文为空）”，但 API 仍返回空字符串。

以下是三种独立查询的合成示例，不是真人笔记或用户反馈。`note` 为对应的完整 `Note`，下表只展示标题；集合中的顺序仅为阅读方便。

| 笔记标题 / 正文 / 标签 | 查询关键词 | `matched_fields` | `snippet` |
| --- | --- | --- | --- |
| `AI 入门` / `动态规划\nAi 案例` / `课程` | `ai 动态规划` | `frozenset({'title', 'body'})` | `动态规划 Ai 案例` |
| `动态规划` / `前` 重复 150 次 / 无标签 | `动态规划` | `frozenset({'title'})` | `前` 重复 119 次后接 `…`，共 120 字符 |
| `AI` / 空正文 / 无标签 | 空字符串 | `frozenset()` | 空字符串 |
