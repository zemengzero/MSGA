## 给 D 的日期转参规则

输入、标签文案建议为“开始日期（含当天，YYYY-MM-DD）”“结束日期（含当天，YYYY-MM-DD）”。空输入转 `None`。本期统一按北京时间 UTC+08:00 解释，不使用机器本地时区。

结束日期包含整日，必须转为**次日 00:00 的排他上界**，不使用 23:59:59。例如选择 2026-11-01 当天，对应北京时间 `[2026-11-01 00:00+08:00, 2026-11-02 00:00+08:00)`，等价 UTC `[2026-10-31 16:00Z, 2026-11-01 16:00Z)`。

```python
from datetime import date, datetime, time, timedelta, timezone

from zhiyeteam.models import ValidationError
from zhiyeteam.search import search_notes

BEIJING = timezone(timedelta(hours=8))

def date_bounds(start_text="", end_text=""):
    """界面调用示例；日期输入采用严格 YYYY-MM-DD。"""
    def parse(text):
        value = date.fromisoformat(text)
        if value.isoformat() != text:
            raise ValueError("日期格式必须为YYYY-MM-DD")
        return value

    try:
        start = (datetime.combine(parse(start_text.strip()), time.min, BEIJING)
                 if start_text.strip() else None)
        before = (datetime.combine(parse(end_text.strip()) + timedelta(days=1),
                                   time.min, BEIJING)
                  if end_text.strip() else None)
    except (ValueError, OverflowError) as exc:
        raise ValidationError("请输入有效日期（YYYY-MM-DD）") from exc
    return start, before

start, before = date_bounds("2026-11-01", "2026-11-01")
notes = search_notes(store, "动态规划", ["课程"],
                     updated_from=start, updated_before=before)
# 回收站查询仍可用 deleted=True；非法区间由 search_notes 抛 ValidationError。
```

界面应捕获 `ValidationError` 显示提示。上述示例供 D 接入，尚未做界面集成或整机演示。
