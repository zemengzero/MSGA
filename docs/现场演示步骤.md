## 常见提问

**这个按钮由哪段代码实现？** 从`ui.py`中对应事件函数开始，再指向业务函数和测试，不只背文件名。具体行号由`docs/功能与代码定位.md`自动生成。

**为什么不用Web或大型框架？** 本次验收要求实体可运行，桌面本地数据减少网络/账号依赖。选择Tkinter/SQLite是为了把主路径和恢复机制做完整；跨平台、协作与云同步不在本版范围。

**为什么SQLite能避免存一半？** `NoteStore._write`先`BEGIN IMMEDIATE`取得写锁，再核对revision和容量；正文、标签、关联、历史在同一事务提交。不是“用了数据库所以所有操作自动安全”。

**两个窗口同时修改怎么办？** 保存带expected_revision，后保存的旧版本应得到ConflictError，保留编辑器内容，可另存或重新读取；看`test_second_connection_cannot_silently_overwrite`。

**为什么改名后链接不坏？** 链接保存UUID，标题只负责显示；别名是可选显示文字。目标删除后源标记仍在，回收站恢复同UUID即可重新访问。

**版本回退会删除后面的历史吗？** 不会，读取旧版本再以新revision保存；`restore_version`不覆盖历史行。

**恢复旧备份会不会丢掉后加的笔记？** 活动库按快照完整替换，但当前库先用在线备份生成保护副本；恢复失败自动回退，回退也失败则禁止继续写入并给保护文件位置。

**这些测试是真实执行吗？** `reports/test_results.json`逐项记录本次实际运行，`frozen_smoke.json`验证打包exe。200篇/2KiB数据的查询数字只代表后端过滤调用，不等于全UI时延或5000篇极限结果。

**每个人做了什么？** 只展示每个人真实账号的commit、diff、PR、测试和能解释的代码。当前基线不能当作四人的历史；尚未完成的任务如实标为计划。
